# 配置与调用网络搜索

网络搜索返回网页摘要和原文链接，供你或 AI 工具继续判断。它是独立能力：添加搜索来源不会让每一条模型对话自动联网。

开始前准备支持服务的地址与凭据。查询词会发送给所选搜索服务；某些服务需要独立付费。读取某个已知网页与按关键词搜索也是不同任务。

## 添加来源

1. 打开左侧“网络搜索”，点击左下角加号。
2. 选择要连接的服务：知乎、Brave、Tavily、Exa、SearXNG 属于网络搜索；Jina Reader 和 Firecrawl 是网页读取。
3. 确认“名称”和“网址”，按服务要求填写 API 密钥或 Access Secret。自建 SearXNG 使用自己的可达服务地址。
4. 添加后在来源详情测试当前配置，检查启用状态与验证结果。
5. 修改了地址或凭据，要重新验证。先前成功不代表新配置有效。

![添加网络搜索来源时选择 Brave 并填写连接信息](images/zh-CN/search-source-add.png)

图中没有填写密钥，因此添加按钮不可用。切换来源类型时请重新读字段说明，不要把知乎 Access Secret 当作另一服务的 API key。

## 在 App 中测试搜索

只有存在符合条件的已启用且当前配置验证通过的搜索来源时，右上方“打开搜索接口调试”才可用。

1. 打开搜索调试，选择已配置的搜索引擎。
2. 在请求 JSON 中填写查询词和结果数量，运行。例如使用下面的完整请求，不要只在 JSON 编辑框内粘贴一个词。
3. 检查返回结果中的标题、摘要和原文链接，打开原文核对上下文。
4. 遇到失败查看当前错误；没有结果时先换更明确的查询词，不直接认定配置失败。

可复制的测试请求：

```json
{
  "engine": "brave",
  "query": "DeepSeek API documentation",
  "limit": 3
}
```

本次真实调用返回 3 条结果，其中一条标题为 `Your First API Call | DeepSeek API Docs`，链接为 `https://api-docs.deepseek.com/`。结果会随时间变化；验证重点是正常返回标题、摘要、可打开的链接，以及实际结果数，而不是要求标题永远一样。

![Brave 查询实际返回三条标题、摘要与链接](images/zh-CN/search-results-success.jpg)

图中是 CLI 实际结果的浏览器阅读视图，不是 App 截图。

结果数 `limit` 的公共范围是 1—20，未指定时为 8；超出范围会拒绝请求，不是自动截成 20。App 调试示例可以先用 3 条，返回不足 3 条不一定是失败。

同一引擎配置多个满足条件的来源会产生歧义，返回 `search_source_ambiguous`。到“网络搜索”来源列表停用不打算使用的同引擎来源，使该引擎只剩一个已启用、当前配置验证通过的来源，再测试。其他引擎不必停用；不要把它理解成自动聚合所有来源，也不要往公共请求里加内部来源 ID。

## 从命令行或工具调用

先用 `omniproxy search query --help` 核对当前版本。已配置并验证 Brave 的实例可以使用：

```sh
omniproxy search query "本周开源模型更新" --engine brave --limit 3 --output json
```

这条命令读取独立 CLI 实例的搜索配置，不能直接使用 App 已保存的来源。如果来源只在 App 中配置，可以先在 App 调试，或用 App 监控台的网关地址进行下面的 HTTP 调用；想用独立 CLI，则先在该实例配置来源，不复制 App 数据库。

成功后从 `results` 读取条目，每项有 `title`、`snippet` 和 `url`；`meta.result_count` 是实际返回数量。CLI 的 JSON 外层先检查 `ok`，再读 `data`；HTTP 则直接返回搜索结果对象。失败时读取错误码与提示。HTTP 调用使用独立的 `POST /v1/search`，不是在聊天请求里随意增加一个 `web_search` 字段，详见[API 参考](14-help-api.md)。

AI 工具需要明确支持调用这条搜索能力或由你把结果交给它。取得摘要也不证明模型已阅读全文，更不能保证回答事实正确。

## 常见问题

| 现象 | 下一步 |
| --- | --- |
| 搜索调试图标灰色 | 检查是否有已启用且当前配置验证通过的网络搜索来源 |
| 认证失败或额度不足 | 检查对应服务的凭据、权限和计费，不改模型服务密钥冒充搜索凭据 |
| 来源有歧义 | 检查同一引擎是否有多个可用来源，保留明确配置 |
| 返回空列表 | 调整查询词和结果数，再看返回状态 |
| 能读网页却不能关键词搜索 | 你可能只添加了网页读取来源，需要另外配置搜索服务 |

需要发送前处理敏感查询词，按[脱敏指南](11-redaction.md)配置相应来源；不要假定模型来源的策略会覆盖另一搜索来源。
