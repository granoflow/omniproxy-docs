# 16 · 附录

需要查一个名称或判断下一步时，可以从下面的术语和常见问题开始。具体操作以对应章节和当前安装版本的帮助为准；旧版本的测试或发布记录不能证明当前安装的全部能力可用。

## 术语表

| 术语 | 含义 |
|------|------|
| OmniProxy | 管理模型来源、提供兼容调用入口并观察调用情况的个人 AI 网关 |
| 本地网关 | 在你的设备上运行、接收客户端请求的 OmniProxy 服务 |
| 协议转译 | 把客户端请求转换为实际来源使用的协议 |
| 原生透传 | 按指定来源转发方法、路径、正文等，不进行协议归一化 |
| 网络搜索来源 | 根据问题或关键词返回候选结果的服务 |
| 网页读取来源 | 根据明确网址返回页面正文的服务 |
| 词表 | 翻译时使用的术语；同名用户版本整表覆盖内置版本 |
| 脱敏 | 发送前按规则处理可解析文本，不能保证不漏检 |
| 调用日志 | 查看具体调用状态与结果的记录 |
| 统计 | 按时间范围汇总的用量和调用指标，与逐条日志有不同保留周期 |
| 第三方工具 | 配合网关使用的外部软件，不是 OmniProxy 自动安装和管理的软件 |

## 常见问题

### OmniProxy 是聊天软件吗？

不是。聊天应用只是调用网关的一类客户端。脚本和其他支持相应协议的工具也可以调用，见 [14 · 帮助与 API 文档](14-help-api.md)。

### 必须安装本地模型才能使用吗？

不必。你可以先连接并验证外部来源，暂不安装本地模型。两类来源可以同时配置，但每个来源和模型都需要分别验证；安装引导见 [01 · 安装与引导](01-getting-started.md)。

### 清空日志之后，为什么统计仍有数字？

逐条日志和长期汇总分别保留。清理日志不代表清空统计，见 [03 · 统计](03-statistics.md)。同样，未知 token 用量也不能解释为零。

### 翻译术语不对怎么办？

先检查实际生效的词表，再按完整同名版本修改和导入；不要把仅含一个修改词条的文件误当作增量补丁。操作见 [10 · 词表与翻译](10-glossary-translation.md)。

### CLI 与桌面版是否会自动共享全部数据？

不会。不同发行物的设置和凭据不是自动共享的；同名模型也不代表已经复用同一份文件。需要复用模型时，使用明确授权的模型存储位置并完成校验，见 [05 · 本地模型管理](05-local-models.md)。词表和规则覆盖通过显式导出、导入迁移，不因复制模型文件而自动生效。

两种发行物可能使用同一个 PATH 命令名，遇到行为不同先确认实际执行的是哪一个 CLI；同时也要检查端口与运行实例。详见 [12 · CLI 与运行时](12-cli-runtime.md)。

### Agent 如何使用 OmniProxy？

MCP 已退役。Agent 使用 CLI 执行命令、读取结构化输出，通过 `--help` 查询当前入口；模型调用使用网关协议。见 [12 · CLI 与运行时](12-cli-runtime.md)。

### 网关连不上，先看哪里？

先核对网关是否运行、客户端使用的地址和凭据，再检查端口或其他运行实例冲突。不要只凭陈旧的诊断文件判断服务仍在运行，也不要先删除数据目录。见 [13 · 运行时系统状态](13-system-states.md)。

### 阿拉伯语界面只是文字靠右吗？

不是。RTL 还涉及布局方向和方向性控件。语言设置见 [04 · 设置](04-settings.md)；不要把布局差异误认为功能缺失。
