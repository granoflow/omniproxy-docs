# 04 · 设置

应用外观、模型文件和外部服务连接不是同一类设置。修改显示语言不会改变模型来源；换一个模型存储目录也不会自动转移你的凭据。先确定要改变的对象，再进入对应页面。

例如，你只是想把模型文件放到另一块磁盘，应使用模型存储设置，而不是移动整个应用状态目录。转移之后还需要检查模型是否可用，不能凭文件复制完成就认定全部设置已迁移。

## 从哪里调整

| 想调整的内容 | 入口或参考 |
|--------------|------------|
| 语言、外观、登录时启动、日志保留 | 应用设置 |
| 模型存储位置 | 设置中的模型存储区域 |
| 下载与测试本地模型 | [05 · 本地模型管理](05-local-models.md) |
| 外部模型地址、凭据与验证 | [06 · 连接外部模型](06-external-models.md) |
| 网络搜索和网页读取来源 | [09 · 网络搜索](09-search-sources.md) |
| 翻译引擎与词表 | [10 · 词表与翻译](10-glossary-translation.md) |
| 外发前处理与复核模型 | [11 · 脱敏](11-redaction.md) |

不同功能使用自己的模型选择和来源配置，不通过一个全局“默认对话模型”替所有任务作决定。

## 语言、外观与登录启动

外观可选择亮色、暗色或跟随系统。当前设置中的语言选择器提供跟随系统、English、简体中文、Deutsch 和 العربية；可见选项应以安装版本为准。

阿拉伯语使用从右到左的布局，不只是把文字靠右。修改语言后应检查页面和方向性控件；不要把显示变化误当成模型、来源或文件发生改变。

开启登录时启动后，仍应检查应用显示的实际登录项状态。系统状态与期望设置未同步时会出现提示，不能只凭开关位置确认系统已经接受设置。

## 模型存储与发行物隔离

模型文件和应用的私有设置分别管理。修改存储位置时，使用应用提供的选择与授权流程；不要通过手工移动 SQLite、凭据或整个状态目录来替代。

独立 CLI 与桌面版不会因为安装在同一台机器上就自动共享所有设置和凭据。需要复用同一外部模型根目录时，两端必须分别获得访问权限并校验模型。词表和规则覆盖使用显式导出、导入，不因共用模型目录而自动生效。

若终端和桌面表现不同，先核对实际使用的发行物、命令路径及运行实例，见 [12 · CLI 与运行时](12-cli-runtime.md)。

## 网关连接设置

网关连接涉及监听地址、端口和代理凭据，与外部服务自身的地址和 API key 不同。客户端需要连接的是 OmniProxy 当前显示的网关地址。

| 项目 | 注意事项 |
|------|----------|
| 仅本机监听 | 用于本机客户端，不等于其他设备也能访问 |
| 所有网络接口 | 扩大访问范围；先配置代理凭据并确认网络环境 |
| 端口 | 修改后检查实际生效地址；冲突不能当作切换成功 |
| 代理密钥 | 用于客户端访问网关，不是第三方来源密钥 |

动态网络地址可能变化，连接时以当前显示的地址为准。不要把一次复制的局域网地址视为永久固定地址。具体连接操作见 [02 · 监控台](02-monitor.md)。

## 日志保留

成功调用与错误调用的正文有不同保留选项，长期统计另行保存。

| 设置 | 当前可选值或含义 |
|------|------------------|
| 成功正文保留 | 6 小时、24 小时、3 天 |
| 错误正文保留 | 7 天、30 天、跟随成功正文 |
| 日志总量上限 | 限制正文存储量；修改后检查是否保存成功 |

默认成功正文保留 24 小时，错误正文保留 7 天，总量上限 500 MiB。正文到期与整条记录删除不是同时发生的：安全元数据有独立保留期。超出上限会触发清理，不保证保留整个时间窗口内的所有正文。

清理日志之前，先完成正在进行的故障排查。清理逐条记录不等于删除长期汇总；统计中可能仍有历史用量，详见 [03 · 统计](03-statistics.md)。若设置保存失败，先处理显示的错误，不把输入框中的草稿当作已生效配置。

## 来源、搜索与翻译设置

外部模型来源保存后需要验证当前配置；停用来源后不能把过去成功的测试当作它仍参与调用的证明。来源的参数和路由规则见 [06 · 连接外部模型](06-external-models.md)。

网络搜索使用独立接口，不存在通过旧 chat “联网”开关自动搜索的设置。厂商自己的字段也不等于 OmniProxy 搜索；需要搜索时按 [09 · 网络搜索](09-search-sources.md) 显式调用。

词表导入使用完整同名覆盖，规则覆盖与允许名单则有各自的校验边界。不要把某一功能的导入方式套到另一功能上；先看相应页面的预览和验证结果。
