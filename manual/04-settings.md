# 设置、存储和日志

打开左侧“设置”。先找到与你的任务有关的一组，不需要为了开始调用模型把所有开关都改一遍。

## 语言、外观与启动

“界面语言”可以跟随系统或选择语言；“外观”可以跟随系统、浅色或深色。更换后检查文字和布局，模型来源不因界面语言改变。

“开机自启”影响登录后的启动；“启动时隐藏窗口”影响启动时是否展开主窗口。隐藏窗口不等于停止网关，关闭窗口也不能单独证明后台已退出。只想暂停新的代理请求，到[监控台](02-monitor.md)点击“暂停代理”；这不会取消已受理的请求。需要退出整个桌面 App 时，使用应用菜单“退出 OmniProxy”（⌘Q），App 会执行 Runtime 退出流程，不能用关闭窗口代替。

“显示推荐动画”只控制界面推荐区域，不改变模型选择或调用能力。

## 模型存储

“默认下载位置”是当前管理模型存储，也是新下载的写入位置。“更多模型文件夹”则登记其他已有目录，两者的文件行为不同：

- 更改默认位置：点击默认位置旁的“更改位置”图标，选择并授权新目录，阅读“迁移模型存储”中的目标、可用空间和预计剩余空间，再决定是否“开始迁移”。迁移会等待模型释放、暂停新的模型写入，验证新位置后才切换；失败时继续使用原位置。“旧副本清理待完成”表示切换已完成但旧副本处理未完，不要手动清空仍在使用的目录。
- 登记已有目录：展开“更多模型文件夹”，添加实际模型目录，原地识别，不自动复制或迁移其中全部文件。移除登记不等于删除原文件。
- 空间不足或位置离线：先恢复磁盘、释放空间或换合适位置；无法确认容量时会明确询问，不把未知当作空间充足。选择目录不等于已经完成迁移。

移动硬盘、NAS 或其他工具目录要先可达，并授予目录访问权限。完整操作见[本地模型](05-local-models.md)。

“显示模型文件位置”决定是否在模型名称下显示路径。截图或报告问题时，如果路径带有用户名和业务目录，请先处理个人信息。

迁移确认框中的“取消”用于开始前放弃选择。开始迁移后，本页没有用于中断迁移的按钮，应等待结果，不靠强退或拔盘取消。旧副本由迁移流程在验证和切换后处理；显示“旧副本清理待完成”时保留现状并通过“关于→报告问题”提供错误与迁移目标，不自行清空旧盘，也不把“更多模型文件夹”中其他工具的文件列入清理。

## 日志总量上限

在“日志”中调整总量上限，单位为 MB。较小上限有利于控制磁盘占用，但旧记录或正文可能更早清理。不要把增大上限当作恢复已被清理正文的方法。

记录与[统计汇总](03-statistics.md)用途不同；详情已经没有正文时，汇总仍可能存在。分享任何日志前检查原文和附件信息。

## MCP 与浏览器模型

“MCP”属于实验功能，默认关闭；启用后才出现[MCP 服务](mcp-services.md)。是否适合长期使用，应结合当前版本支持情况，不因显示开关就假定全部远程服务兼容。

“允许 Chrome / Edge 模型接入”控制浏览器内置模型桥接，默认关闭。需要时开启，在 Chrome 或 Edge 的配套扩展中启用 OmniProxy 连接；等待设置中显示“扩展已连接，模型可用”，再到“本地模型”查看相应条目并做调用测试。若显示“等待浏览器扩展连接”，只打开 App 开关还不够；“分享已关闭”或“模型不可用”应先在浏览器端恢复条件。

这需要配套扩展与浏览器模型实际可用，不是打开开关就获得任意本地模型。当前若提示“扩展商店链接尚未提供”，手册无法提供一个可安装的正式扩展入口；不要猜下载地址或安装来历不明的扩展，可保持关闭并使用其他已验证模型。

## 版本、隐私和帮助

在“关于”查看实际版本、打开产品手册或报告问题。报告时提供版本、操作步骤和已去除敏感信息的错误；不要直接附来源密钥或工作原文。独立的[产品隐私政策](https://github.com/granoflow/omniproxy-docs/blob/main/docs/omniproxy-privacy-policy.md)说明其适用范围，不以本章代替法律文本。
