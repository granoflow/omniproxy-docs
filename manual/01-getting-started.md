# 01 · 安装与引导

首次设置不是一次把所有模型装齐，而是选择现在需要的能力。你可以先连接外部模型，暂不下载本地翻译模型；以后需要本地推理时，再到「本地模型」添加和测试。

本章介绍 macOS 桌面版和 CLI 的首次设置。准备好与你的设备匹配的安装包；如果要连接外部服务，还需要该服务的地址和凭据。不要把密钥放进截图、聊天记录或共享文件。

## 设置前先分清两类内容

模型文件与应用自身的设置分开管理。首次引导使用默认存储位置，不要求你先选择一个总目录。以后管理模型文件时，不要把移动模型文件误当作转移了来源配置和凭据。

例如，你只想让脚本调用一个已有的外部服务，可以在第一步选择不预装翻译模型，在第二步添加并验证来源，再确认设置。不添加网络搜索来源不会阻止这条路径，但也不会获得网络搜索能力。

## 完成五步引导

桌面版首次打开时进入引导；CLI 在交互式终端运行：

```bash
omniproxy init
```

终端会显示「OmniProxy 初始化」，并从选择翻译模型开始。按提示输入选项；不要把这条交互命令接在没有终端输入的管道后面。

| 步骤 | 你要做什么 | 继续前应看到什么 |
|------|------------|------------------|
| 1 · 选择翻译模型 | 选择当前提供的 Hy-MT2 条目，或不预装 | 选项反映你的选择；设备建议不等于必须安装 |
| 2 · 连接外部模型 | 添加服务地址和凭据，并测试连接 | 已添加来源全部按当前配置验证通过；没有来源也可继续 |
| 3 · 连接网络搜索 | 按需要添加搜索或网页读取来源，并测试 | 已添加来源全部按当前配置验证通过；没有来源也可继续 |
| 4 · 确认设置 | 核对翻译模型、来源和实际下载清单 | 只列出仍需下载的选定模型；无需下载时明确显示 |
| 5 · 完成设置 | 查看执行结果，等待所需任务完成或处理错误 | 桌面版在完成后可进入工作台；CLI 输出初始化执行结果 |

确认页不直接编辑设置。桌面版使用「上一步」返回；CLI 输入提示中的 `b` 返回上一步。确认前核对下载清单，不以旧手册中的固定大小代替当前目录显示的文件大小。

当前引导不要求安装对话基座模型。已就绪且与所选目录条目身份一致的模型可被复用，不会因为再次确认引导而要求下载另一份。

## 来源验证不通过时

地址或凭据修改之后，需要重新测试。此前成功的结果不能证明新配置可用。

| 情况 | 处理方式 |
|------|----------|
| 来源刚添加，还没有验证 | 使用来源的测试操作，查看返回结果 |
| 修改了来源配置 | 重新测试当前配置 |
| 连接或认证失败 | 根据错误检查服务地址、网络和凭据，再测试 |
| 当前不准备使用这个来源 | 移除这次添加的来源后再继续，不把失败当作成功 |

外部模型和网络搜索是两类来源：前者提供模型调用，后者提供搜索或网页读取。连接外部模型不会自动配好搜索服务。

## 下载与后续管理

所选模型需要下载时，确认后才开始相应任务。文件下载和校验完成之前，不能仅凭文件已经出现在磁盘上就认为模型可调用。具体的下载状态、恢复、调试和删除方式见 [05 · 本地模型管理](05-local-models.md)。

初始化完成后，可以继续配置 [06 · 连接外部模型](06-external-models.md) 和 [09 · 检索来源](09-search-sources.md)。需要查看调用结果与运行情况时，进入监控台。

## 移除应用与数据

在 Finder 删除应用不等于删除它保存的设置和模型。应用内的「准备移除 OmniProxy…」会让你选择保留或删除数据；删除之前先阅读实际显示的范围，结束后检查逐项结果，不把部分成功当作完全清除。

CLI 也提供数据移除操作。下面的命令会确认执行删除，**不是查看范围的命令**；仅在你确实决定移除对应数据时使用：

```bash
omniproxy data remove --scope private --yes
omniproxy data remove --scope all --yes
```

`private` 针对当前发行物的私有设置、状态及关联凭据；`all` 还涉及经归属校验的受管内容。不要用手工删除整个存储根目录替代范围确认：外部或共享模型、用户原始文件以及无法证明归属的文件不应被当作应用垃圾。出现失败时，按结果中的恢复提示处理。
