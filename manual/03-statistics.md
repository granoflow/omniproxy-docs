# 读懂统计数字

“统计”汇总一段时间里的用量；“监控台”帮助你查看某一次请求。想查一次失败，先看[调用记录](02-monitor.md)；想比较这周和上周，再看统计。

## 先选范围

1. 打开左侧“统计”。
2. 选择日、周或月，并切到包含目标调用的日期。
3. 查看模型用量、趋势、搜索和缓存等当前可用部分。
4. 点击支持下钻的用量项时，检查关联记录的时间与实际模型。

空图表不代表一段时间内发生过请求且消耗为零；先确认范围内确实有调用记录。

## 用量记在实际执行的模型上

假设工具请求 `chat`，用途映射把它交给来源 A 的模型。用量归属实际执行的来源 A 和模型，而不是再给 `chat` 多记一份。多个别名落在同一实际目标上时，不能把别名当作不同供应商账单。

| 显示情况 | 应怎样理解 |
| --- | --- |
| 数值为 0 | 已知数字确实为零 |
| 未知或没有数值 | 没有可靠的用量信息，不能自行补为零 |
| 没有记录 | 当前范围没有可汇总的数据，先查日期和调用是否发生 |

界面可能用“—”表示没有可展示的数字，用“未知 N”标记缺少计量的调用；整个时段都缺计量时会提示“本时段没有可用 Token 计量”。这些都不能读作 0。Token 是模型用量单位，不是金额。

## 搜索和缓存

搜索任务和上游来源调用不是同一个计数单位。一次任务可能涉及多次来源调用，先看表头再比较数字。

缓存命中表示复用了已有结果；它不等于供应商重新执行了一次模型调用。页面中的缓存“省”与节省量按记录中的 Token 计算，汇总来自各条缓存记录的节省 Token；它不是人民币、美元或已经核实的账单折扣。实际付费以供应商账单为准。

## 数字对不上时

按顺序检查：同一时间范围、同一发行物与数据实例、同一实际来源和模型、已知数值还是未知、是否命中了缓存。较旧的调用正文被清理后，汇总也可能仍保留。

日志空间上限在[设置](04-settings.md)中调整。不要为让数字一致而删除原始记录；先定位差异来自哪一种口径。

当前统计页没有账单导出或自动对账入口。核对费用时，在供应商账单中选择相同时间范围，再按实际来源、模型和调用记录比较；Token 用量与金额不是同一单位，未知用量也不能补零。需要提供排错材料时，按[调用记录](02-monitor.md)检查和去除敏感信息，不寻找本页不存在的账单导出按钮。
