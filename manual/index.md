# OmniProxy 用户手册

OmniProxy 是运行在你电脑上的 AI 网关。它把云端 API、本地模型、网络搜索和远程工具统一收拢在一处管理；你平时习惯的聊天、编程或 Agent 软件无需更换，只要客户端支持对应的模型协议与能力，并将服务地址指向 OmniProxy，即可通过网关进行调用。

第一次接触 OmniProxy，请从**开始使用**读起：先准备一个可用模型，再把常用工具连上网关。日常使用中遇到配置、排错或命令查询需求，可按下方目录直接跳转到对应章节。

## 阅读前须知

- **分清两把密钥**：上游供应商的 API Key 保存在 OmniProxy 的来源配置里，用于向厂商发起请求；OmniProxy 生成的**代理密钥**填在你的第三方 AI 工具里，用于访问本机网关。请注意，远程模型服务由对应供应商按 API 用量计费，网页端聊天会员通常不包含 API 调用权限。
- **明确数据流向**：使用本地模型时，推理在你的电脑上完成；一旦选择远程模型、网络搜索、远程翻译或远程 MCP 服务，请求内容就会发送给对应的外部服务商。[发送前文本脱敏](11-redaction.md)需按来源单独开启且存在规则识别边界，不能保证拦截所有敏感内容。调用记录中可能留存你的提问原文与回答，截图或导出分享前请先检查脱敏。
- **版本与配图说明**：本手册适用于 0.1.0 开发版，界面以 macOS 为例；基于 2026-10-25 版本编写。若其他平台或安装包暂未提供某项界面入口，请以当前版本的实际界面和 `--help` 帮助输出为准。手册配图均采自隔离测试环境：展示配置步骤、空列表或故障状态的原生 App 截图仅用于指示入口位置；标有“浏览器阅读视图”的配图来自 CLI 真实返回字段的可视化展示，并非原生 App 界面；单次调用成功的截图仅代表该条测试输入通过，不代表模型的所有扩展能力均已兼容。
