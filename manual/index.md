# OmniProxy 使用手册

OmniProxy 把你使用的 AI 工具和模型连接起来。模型的地址、凭据和选择在这里管理；聊天、写代码或创作仍在原来的工具里进行。

第一次使用，从“开始使用”读起，先接通一个模型，再连接你常用的 AI 工具。已经完成接入，可以按下面的目录查找配置方法、日常操作或故障处理。

## 使用前需要知道

模型服务的 API 密钥相当于供应商的通行证；网关的代理密钥相当于进入 OmniProxy 的通行证。它们用途不同。远程服务由供应商计费，普通聊天会员通常不能代替 API 权限。

选择本地模型时，请求由对应本机引擎处理；选择外部模型、搜索或远程翻译服务时，相应内容会发送给该服务。[脱敏](11-redaction.md)需要配置，也可能漏检。调用记录可能包含原文和回答，分享前也应检查。

本手册按 2026-10-25 的 0.1.0 开发版源码与 macOS Debug 界面编写。正文中的截图来自隔离测试环境；虚构名称、空列表和故障示例会在附近说明。其他平台或安装版本没有同一入口时，先查看该版本的帮助，不把开发版画面当作正式发行承诺。

配图请连同紧邻说明阅读：标明配置、空状态或故障的图用于认识入口和恢复；成功结果图给出本次输入、实际输出和成功判断。写明“浏览器阅读视图”的图来自真实 CLI 字段，不能当作 App 界面；原生调用图也只证明所展示的那次操作，不证明所有能力都通过。
