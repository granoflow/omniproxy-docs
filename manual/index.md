# OmniProxy 产品手册

适用版本：OmniProxy 0.1.0 开发版（2026-09-10）。以当前安装版本的 `--version` 和 `--help` 核对可用入口。本手册不代表跨平台正式发布验收已完成。

OmniProxy 是个人 AI 网关：你在这里管理本地模型、连接外部模型服务，并查看调用情况。真正使用模型的仍可以是你熟悉的应用、脚本或第三方客户端，不必换到一个新的聊天界面。

例如，你想让一个客户端调用自己的模型来源，先完成首次设置并验证来源，再按客户端需要配置网关连接。调用后到监控台看结果；想比较一段时间的用量，再看统计。

## 分清客户端、网关和模型来源

```
你的应用 / 脚本 / 第三方客户端
              │
              ▼
       OmniProxy 网关
              ├── 本地模型
              ├── 外部模型服务
              ├── 网络搜索 / 网页读取来源
              └── 调用记录与统计
```

网关连接成功不代表每个模型来源都可用。配置或修改来源后，先验证该来源，再检查一次真实调用的结果；不要仅凭下载完成、列表中出现模型或 HTTP 成功状态判断所有能力都正常。
