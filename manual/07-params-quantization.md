# 选择模型时看懂大小与格式

下载前最有用的判断是：它能做你的任务吗、电脑能运行吗、文件放得下吗。模型名称里的参数和量化标签只是辅助信息。

| 信息 | 对使用的意义 |
| --- | --- |
| 参数量，例如 1.8B、7B | 模型规模；更大不自动等于更适合每个任务 |
| 量化，例如 4-bit、8-bit | 权重存储精度，会影响大小、内存和结果；不同版本要分别看要求 |
| 文件大小 | 下载和磁盘预算，不能直接当作运行内存需求 |
| 运行格式与引擎 | 决定当前发行物能否加载；有 GGUF 文件不等于所有 GGUF 都能运行 |
| 任务能力 | 对话、翻译、语音、图片等，必须核对具体支持情况 |
| 设备适用性 | 当前机器的运行条件，不等于已经完成真实测试 |

同一个模型家族会有不同工件和量化版本。下载时核对具体条目，不把别的工具中同名文件当成可直接替代的版本。

## 实际选择顺序

1. 先明确任务，例如“把英文短文译成中文”，而不是笼统选一个最大模型。
2. 在目录中按任务查找，阅读设备提示、工件大小和许可。
3. 确认存储位置在线、空间足够，再下载。
4. 用一份小而有代表性的输入运行调用测试，检查内容质量、速度和占用。
5. 确认满足自己的任务后再加入代理。

设备筛选、目录登记和加载成功分别证明不同事情。不要把其中一项推导成任意输入都能正确处理。具体步骤见[本地模型](05-local-models.md)。
